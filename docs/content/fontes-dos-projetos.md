# Fontes e limites dos estudos de caso

Revisão em 14/10/2026. Foram lidos os repositórios públicos nas versões disponíveis nessa data. A inspeção de código e documentação confirma a presença das implementações descritas, mas não substitui uma demonstração funcional completa, medição de resultados nem confirmação de autoria individual.

Decisões descritas no portfólio são decisões dos projetos. Atribuição pessoal de cada implementação deve ser confirmada antes de aparecer como afirmação biográfica. Nenhum caso apresenta números de impacto sem evidência.
