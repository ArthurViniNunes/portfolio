# Decisões arquiteturais

As ADRs descrevem decisões com efeito estrutural, alternativas e consequências. Aceita significa adotada nesta implementação; publicação e métricas continuam dependentes de verificação. Não é necessário criar uma ADR para cada componente.

| ADR | Decisão |
| --- | --- |
| [001](ADR-001-react-node-foundation.md) | React + TypeScript; Node apenas em desenvolvimento/build |
| [002](ADR-002-static-react-router-and-hosting.md) | React Router, pré-renderização e hospedagem estática |
| [003](ADR-003-versioned-content-and-search.md) | Conteúdo tipado, evidências e busca local |
| [004](ADR-004-bilingual-static-routes.md) | URLs e HTML próprios para português e inglês |
| [005](ADR-005-light-dark-theme.md) | Tokens e preferência persistida de tema |
| [006](ADR-006-hero-motion-and-accessibility.md) | Direção visual e limites do movimento |
| [007](ADR-007-resume-catalog.md) | Currículos por atuação e idioma |
| [008](ADR-008-repository-and-quality.md) | Organização frontend e verificações |
| [009](ADR-009-contact-without-api.md) | Contato direto e cópia com fallback |
| [010](ADR-010-brand-and-global-motion.md) | Marca vetorial, preferência global e movimento expressivo |
| [011](ADR-011-profile-and-recommendation-provenance.md) | Biografia e depoimentos com fontes, traduções e busca |

Quando uma decisão mudar, registrar a razão e a ADR sucessora. Não presumir publicação, aprovação visual, métricas ou conteúdo profissional a partir destes registros.
